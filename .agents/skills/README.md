# Skills

Each folder holds one skill: a `SKILL.md` whose front matter says when to use
it, plus any `references/` and `scripts/` it needs. Agents find them through
[AGENTS.md](../../AGENTS.md); Claude Code through [CLAUDE.md](../../CLAUDE.md).

Skills are copied unchanged from Stacey Vetzal's guidelines repository and keep
its MIT licence. To update one, copy the newer version over it; do not edit it
here. Ruff skips this folder so the copies stay byte-identical.

| --- | --- | --- |
